# Capstone Project: Urbanization and Solid Waste in Kigali City

## Project Description
This project examines the impact of urbanization on solid waste generation in Kigali City from 2010 to 2025.

## Folder Structure
- raw_data/: Original datasets (not modified)
- processed_data/: Cleaned datasets
- scripts/: R/Python scripts for data cleaning and analysis
- outputs/: Figures, tables, and maps
- metadata/: Data dictionaries and documentation
